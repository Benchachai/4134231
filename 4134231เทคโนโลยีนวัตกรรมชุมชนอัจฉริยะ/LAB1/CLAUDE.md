# CLAUDE.md

## ภาพรวมโปรเจกต์
- โปรเจกต์นี้เป็นระบบต้นแบบสำหรับแจ้งเหตุเพลิงไหม้
- มุ่งเน้นการแสดงสถานะการตรวจจับควันและเปลวไฟ พร้อมแจ้งเตือนผู้ใช้อย่างรวดเร็ว
- โครงสร้างแยกเป็น Frontend สำหรับ UI และ Backend สำหรับประมวลผลข้อมูลและส่งการแจ้งเตือน

## Stack ที่ใช้
- Frontend: Next.js + React
- Backend: API service แยกส่วนสำหรับจัดการสถานะระบบและการแจ้งเตือน
- การออกแบบ UI: รองรับทั้งมือถือและเดสก์ท็อป
- ข้อมูล: ใช้ข้อมูลสถานะระบบและประวัติแจ้งเตือนที่สามารถดูย้อนหลังได้

## คำสั่งพัฒนา / Build
- ติดตั้ง dependency: npm install
- เริ่มเซิร์ฟเวอร์สำหรับพัฒนา: npm run dev
- Build สำหรับ production: npm run build
- เริ่มเวอร์ชันที่ build แล้ว: npm run start
- หาก Backend แยกส่วนให้ใช้คำสั่งของแต่ละ service ตามที่กำหนดในโปรเจกต์นั้น ๆ

## Convention การพัฒนา
- ใช้ชื่อไฟล์และชื่อตัวแปรเป็นภาษาอังกฤษเพื่อความสอดคล้องและง่ายต่อการดูแล
- ใช้ภาษาไทยสำหรับข้อความ UI และเอกสารที่ผู้ใช้เห็นเพื่อให้เข้าใจง่าย
- แยกส่วนงานให้ชัดเจน: UI, API, state, และ logic
- ตั้งชื่อตัวแปรและ component ให้สื่อความหมาย เช่น DashboardPage, AlertCard, FireStatus
- ควรเขียนโค้ดให้เล็ก ชัดเจน และแยกความรับผิดชอบออกจากกัน

## กฎสำคัญสำหรับ AI
- ให้ยึดตามความต้องการจาก SRS: แดชบอร์ด, สถานะแบบเรียลไทม์, ประวัติแจ้งเตือน, และการรองรับอุปกรณ์ต่าง ๆ
- สำหรับต้นแบบให้ใช้ข้อมูลจำลอง/mock ได้หากยังไม่มีเซ็นเซอร์จริงเชื่อมต่อ
- อย่าเพิ่มฟีเจอร์ที่อยู่นอกขอบเขต เช่น การควบคุมอุปกรณ์ดับเพลิงอัตโนมัติ หรือการวิเคราะห์เชิงลึก
- ให้โฟกัสที่ความง่ายในการใช้งาน ความเสถียร และความสามารถในการขยายตัวในอนาคต
- หากมีการเปลี่ยนแปลงขอบเขตหรือคุณสมบัติ ให้ปรับปรุง SRS ให้ตรงกับการพัฒนา
- หลีกเลี่ยงการเปิดเผยข้อมูลสำคัญหรือความละเอียดอ่อนใน log และ alert ที่ไม่จำเป็น
