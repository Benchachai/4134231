Frontend (Next.js + MUI) - Run Instructions

1. ติดตั้ง dependencies

```bash
cd LAB1/frontend
npm install
```

2. รัน development server (พอร์ต 3001)

```bash
npm run dev
```

3. เปิดเว็บเบราว์เซอร์ไปที่

```
http://localhost:3001
```

4. ข้อสังเกต
- Backend / Swagger ควรรันที่ `http://localhost:3000` (Swagger UI: `/docs`) เพื่อให้ปุ่มเชื่อมต่อ API ในหน้าใช้งานได้
1. ต่อจาก backend ผ่าน api (ดู swagger ได้ที่ http://localhost:3000/api-docs)

2. ใช้ mobile interface เป็นหลัก

3. ใช้ template จาก https://m3.material.io/

4. ใช้ next.js
