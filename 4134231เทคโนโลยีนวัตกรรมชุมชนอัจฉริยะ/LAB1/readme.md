# โครงการระบบธนาคารขยะ

## ภาพรวมโปรเจ็ค
ระบบนี้เป็นเว็บแอปสำหรับบริหารจัดการธนาคารขยะในชุมชน โดยช่วยให้สมาชิกสามารถลงทะเบียนขยะที่นำมาฝาก, ติดตามสถานะการจัดการขยะ, แลกคะแนน, และดูสถิติการรีไซเคิลผ่านอุปกรณ์มือถือและคอมพิวเตอร์

## ฟีเจอร์หลัก
- ลงทะเบียนขยะที่นำมาเข้าสู่ธนาคารขยะ
- จัดการข้อมูลประเภทขยะและอัตราคะแนน
- ติดตามรายการฝาก-ถอนขยะของสมาชิก
- แสดง Dashboard สถานะการรีไซเคิลและคะแนนสะสม
- รองรับการใช้งานบนมือถือและ Desktop ด้วย UI ที่ตอบสนอง

## โครงสร้างโปรเจ็ค
```
413423 เทคโนโลยีนวัตกรรมชุมชนอัจฉริยะ/
├── LAB1/
│   ├── ARCHITECTURE.md    # เอกสารสถาปัตยกรรมระบบ
│   ├── CLAUDE.md          # สรุป SRS และสถาปัตยกรรมโดยใช้ AI
│   ├── SRS.md             # ข้อกำหนดซอฟต์แวร์ (Software Requirements Specification)
│   └── readme.md          # เอกสารภาพรวมโปรเจ็คและโครงสร้างไฟล์
```

## รายละเอียดไฟล์
- `ARCHITECTURE.md` : อธิบายสถาปัตยกรรมระบบ รวมถึงส่วนติดต่อผู้ใช้, เซิร์ฟเวอร์, และฐานข้อมูล
- `CLAUDE.md` : สรุปเนื้อหา SRS และสถาปัตยกรรมสำหรับอ้างอิงอย่างรวดเร็ว
- `SRS.md` : ระบุข้อกำหนดทั้งฟังก์ชันและไม่ใช่ฟังก์ชันของระบบ
- `readme.md` : แสดงภาพรวมโปรเจ็ค โครงสร้างไฟล์ และแนวทางใช้งานเอกสาร

## วิธีใช้งาน
1. อ่านเอกสารใน `SRS.md` เพื่อเข้าใจฟังก์ชันและข้อกำหนดของระบบ
2. ดู `ARCHITECTURE.md` เพื่อวางแผนการพัฒนาสถาปัตยกรรม
3. ใช้ `CLAUDE.md` เป็นสรุปสำหรับอ้างอิงเร็ว
4. กลับมาดู `readme.md` เพื่อเข้าใจโครงสร้างไฟล์และเอกสารทั้งหมด
